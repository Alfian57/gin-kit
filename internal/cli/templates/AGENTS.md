# AGENTS.md

## Project overview

This project was generated by GinKit. The `framework` edition uses a versioned
GinKit runtime for generic HTTP and lifecycle behavior; the `starter` edition
keeps that code in this repository for learning. Keep the explicit flow:
router -> handler -> service -> repository -> database.

## Commands

- `ginkit run`
- `ginkit build`
- `ginkit check`
- `ginkit explain architecture`
- `ginkit generate resource <name>`
- `ginkit generate resource <name> --dry-run`
- `ginkit db up`

## Rules

- Keep documentation and user-facing text in English.
- Pass `context.Context` through service and repository boundaries.
- Put schema changes in `migrations/`; never use auto-migration in production code.
- Preserve request IDs and the standard error envelope across new handlers.
- Assign new endpoints to the general, auth, or expensive rate-limit class.
- Never trust forwarded client IP headers without an explicit trusted proxy CIDR.
- Add tests for new behavior.
- Keep the project module path in `go.mod`; never replace it with the GinKit
  module path. Customize framework behavior through public options, hooks,
  middleware, and interfaces before forking the runtime.
- Keep the Tasks example useful as a reference implementation when it is enabled.
