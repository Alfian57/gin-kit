## Rules

- Keep documentation and user-facing text in English.
- Pass `context.Context` through service and repository boundaries.
- Put schema changes in `migrations/`; never use auto-migration in production code.
- Preserve request IDs and the standard error envelope across new handlers.
- Assign new endpoints to the general, auth, or expensive rate-limit class.
- Never trust forwarded client IP headers without an explicit trusted proxy CIDR.
- Add tests for new behavior.
