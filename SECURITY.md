# Security Policy

Please do not report security vulnerabilities in public issues.

Use GitHub's private vulnerability reporting feature from the repository
Security tab. Include a private description, reproduction steps, affected
versions, and a suggested severity. We will acknowledge the report and
coordinate a fix and disclosure timeline.

Generated projects are starting points, not a substitute for a security review. Change all development secrets before production, use HTTPS, review migrations, and configure secure cookies and token keys.
